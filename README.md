# 🌱 Leafy Plant Selling Platform with AI Plant Assistant

This project is a web-based e-commerce platform for selling indoor and outdoor plants.
It includes an AI-powered plant assistant chatbot that helps users with plant care,
problem diagnosis, and correction suggestions.

## 🚀 Features

### Basic Features
- User registration and login
- Indoor and outdoor plant categories
- Product listing and detailed plant pages
- Add to cart and checkout
- Order history and management
- Admin panel for product management

### Advanced Features
- 🤖 AI-powered plant care chatbot
- 🖼 AI-assisted plant image analysis
- Step-by-step plant care guidance
- Beginner-friendly responses

## 🛠 Tech Stack
- Frontend: React / Next.js
- Backend: Node.js, Express
- AI: Large Language Model (LLM)
- Database: MongoDB / MySQL

## 🎯 Objective
To provide a smart and user-friendly platform that not only sells plants
but also helps users take better care of them using AI assistance.

## 📌 Future Scope
- Weather-based care recommendations
- Plant care reminders
- Community discussion forum
- Mobile application
